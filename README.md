## Features

- **Minimal UI:** Clean layout focused on readability and visual hierarchy.
- **Responsive Layout:** Adapts cleanly across mobile, tablet, and desktop viewports.

## Tech Stack

- **Core:** React 18, TypeScript
- **Styling:** Tailwind CSS v3
- **Build & Tooling:** Vite, ESLint, pnpm

## Getting Started

```sh
git clone https://github.com/fahadshahbaz/leya-law.git
cd leya-law
pnpm install
pnpm dev
```

Build for production:

```sh
pnpm build
```
